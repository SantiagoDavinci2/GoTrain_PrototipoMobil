📋 Pantallas del Prototipo

Pantalla 1

Login / Registro

Acceso con email/contraseña y OAuth Google. Validaciones en tiempo real y redirección al onboarding.

→ HU-01: Registro e Inicio de Sesión
Pantalla 2

Retos y Desafíos

Desafíos individuales y grupales con seguimiento de progreso, ranking entre amigos y desafíos 1v1. Incluye una pestaña de Actividad: un feed social integrado que muestra los eventos de los retos (logros, superaciones, nuevos participantes) en vez de posts genéricos.

→ HU-08: Desafíos Individuales y Grupales · HU-04: Actividad Social de Retos
Pantalla 3

Registro de Entrenamiento

Selección de ejercicios por grupo muscular, configuración de series/reps/peso y temporizador de sesión.

→ HU-02: Registro de Entrenamiento
Pantalla 4

Perfil de Usuario

Foto, bio, estadísticas clave, racha de días, badges desbloqueados e historial de entrenamientos recientes.

→ HU-03: Perfil · HU-07: Gamificación
Pantalla 5

Coach Virtual IA

Chat con IA que genera rutinas personalizadas basadas en el historial del usuario. Importación directa al log.

→ HU-06: Coach Virtual con IA

🛠️ Stack Tecnológico

Frontend: React Native
Backend: Python / Flask
DB: PostgreSQL
IA: Claude API (Anthropic)
GPS: Google Maps API
CI/CD: GitHub Actions
